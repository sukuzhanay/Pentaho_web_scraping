# Web scraping con Pentaho — dos enfoques

Dos transformaciones para comparar extracción web con JavaScript y con expresiones regulares.

## Scope

Ambos flujos incluyen petición HTTP, filtrado y separación de filas. Uno contiene ScriptValueMod y el otro RegexEval. El HTML remoto y los plugins pueden haber cambiado desde la práctica.

## Technology / Material

Pentaho Data Integration · HTTP · JavaScript · regex
